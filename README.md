# みんなの大富豪

部屋コードで3〜5人が集まって遊べる、スマートフォン対応のオンライン大富豪です。ゲームの状態はD1に保存され、参加者の画面は約1.5秒ごとに同期します。手札は自分の画面にだけ返す設計です。

## 公開サイト

https://daifugo-friends-2026.adoreddisc16.chatgpt.site/

## 遊び方

1. 名前を入れて部屋を作ります。
2. 招待リンクか5文字の部屋コードを友達に送ります。
3. 3人以上そろったら部屋主が開始します。
4. 同じ枚数でより強いカードを出すか、パスします。8切りと4枚革命に対応しています。

シングル・同じ数字の2〜4枚出し、♣3からの開始、ジョーカー1枚に対応しています。部屋主は開始前に次のローカルルールを切り替えられます。

- スペ3返し、革命、8切り、9切り、10捨て
- イレブンバック、Qボンバー、4止め、ろくろ首、救急車

追加ルールは一般的な遊び方に合わせていますが、地域差があるためこのサイト内の説明を基準にしてください。階段、縛り、都落ち、カード交換は未対応です。

## 実装

- `worker/index.template.js`: Worker APIとD1を使った部屋・対戦処理
- `public/index.html`: UI、招待リンク、1.5秒間隔の状態同期
- 対戦部屋用テーブルは、最初のAPIアクセス時にD1へ作成されます。
- `.openai/hosting.json`: SitesプロジェクトとD1バインディング

Workersを実行できるホスティング先を使います。GitHub Pagesだけでは部屋状態を共有できないため、GitHubはソース管理と公開、対戦APIはD1付きのWorkerホスティングを使います。
